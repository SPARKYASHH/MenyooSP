# PUBG Dance Pack by SPARKYASHH

English · [Русский](README_RU.md)

25 PUBG dances adapted and refined by **SPARKYASHH** for the GTA V female multiplayer character. Original animations belong to PUBG / KRAFTON.

## Choose your edition

| Edition | What it provides | Who it is for |
| --- | --- | --- |
| Menyoo ASI | A dedicated SPARKYASHH dance section and automatic loop settings | Players who want all dances together in the menu |
| Manual / Standard Menyoo | Animation DLC, favorites file and entries for merging existing favorites | Players keeping their standard Menyoo installation |
| Blender | Animation scenes with the GTA female MP skeleton | Creators who want to inspect or edit the animations |

**Release preparation is in progress.** The menu build needs an in-game test; the complete DLC and final Blender scenes still need packaging. No complete installation downloads are published here yet.

The pack contains Victory Dances 11, 14, 20, 37, 41, 44, 52, 56, 62, 74, 81, 85, 86, 99, 102, 110, 114, 131 and 175; BBoom BBoom; MALATANGHLU; and four unidentified dances labelled Dance 1–4. See [the catalogue](DANCE-LIST.csv) for exact dictionary names and playback modes.

20 dances loop. Dance 1, Victory Dance 11, Victory Dance 20, BBoom BBoom and MALATANGHLU finish automatically. Repetitions in the last three are already baked into their animation files.

GTA V Legacy is the initial target. Enhanced compatibility has not been verified. Animations are intended for Story Mode.
