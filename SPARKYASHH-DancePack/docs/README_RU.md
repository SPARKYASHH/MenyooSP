# PUBG Dance Pack by SPARKYASHH

[English](README.md) · Русский

25 танцев PUBG, адаптированных и доработанных **SPARKYASHH** для женского MP персонажа GTA V. Исходные анимации принадлежат PUBG / KRAFTON.

## Какой вариант выбрать

| Вариант | Что внутри | Кому подходит |
| --- | --- | --- |
| Menyoo ASI | Отдельный раздел SPARKYASHH с автоматическим выбором повторения | Тем, кто хочет видеть весь пак в одном разделе меню |
| Ручная установка / обычный Menyoo | DLC анимаций, готовое избранное и строки для добавления в своё избранное | Тем, кто хочет сохранить обычный Menyoo |
| Blender | Сцены с анимациями и скелетом женского MP персонажа GTA | Тем, кто хочет просматривать или редактировать танцы |

**Выпуск готовится.** Меню нужно проверить в игре; полный DLC и финальные Blender-сцены ещё предстоит упаковать. Готовые установочные архивы пока не опубликованы.

В паке: победные танцы 11, 14, 20, 37, 41, 44, 52, 56, 62, 74, 81, 85, 86, 99, 102, 110, 114, 131 и 175; BBoom BBoom; MALATANGHLU; четыре неопознанных танца с условными названиями Dance 1–4. Точные названия файлов и режимы — [в каталоге](DANCE-LIST.csv).

20 танцев зациклены. Dance 1, Victory Dance 11, Victory Dance 20, BBoom BBoom и MALATANGHLU заканчиваются самостоятельно. Повторы последних трёх уже записаны в анимации.

Первый выпуск предназначен для GTA V Legacy. Совместимость с Enhanced пока не проверена. Анимации предназначены для сюжетного режима.
