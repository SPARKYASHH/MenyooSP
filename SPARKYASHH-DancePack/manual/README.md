# Manual installation — standard Menyoo

[Русский](README_RU.md)

Adaptation and fixes: **SPARKYASHH**. Original animations: PUBG / KRAFTON.

These favorites reference the pack's 25 `pubg@VD_*.ycd` files. Install the animation DLC using the release instructions first. Placing YCD files in `menyooStuff` does not install them.

1. Close GTA V and back up `menyooStuff/FavouriteAnims.xml`.
2. To replace your favorites, copy this edition's `menyooStuff/FavouriteAnims.xml` into the game's matching folder.
3. To keep existing favorites, insert the lines from `FavouriteAnims-entries.txt` immediately before `</PedAnims>` in your current file instead.
4. In Story Mode, choose the female multiplayer character. Open Menyoo → Player Options → Animations → Favorites, then select a `pubg@VD_…` entry with clip `dance`.

Standard Menyoo shares playback settings across animations. Disable Loop for Dance 1, Victory Dance 11, Victory Dance 20, BBoom BBoom and MALATANGHLU. Enable Loop for the other 20 dances. Repetitions for 20 / BBoom BBoom / MALATANGHLU are already baked into the files.

Use full-body playback without position locking. ASI Edition selects each dance's playback mode automatically.

[GTA V Mod Switcher by SPARKYASHH](https://github.com/SPARKYASHH/GTAV-Mod-Switcher) moves selected mods out of the game folder and restores your Story Mode setup.
