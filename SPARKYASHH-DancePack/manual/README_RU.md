# Ручная установка — обычный Menyoo

Адаптация и исправления: **SPARKYASHH**. Исходные анимации: PUBG / KRAFTON.

Этот комплект избранного предназначен для 25 файлов `pubg@VD_*.ycd` из пака. Для их загрузки в игру нужен установленный DLC анимаций. Копирование YCD в `menyooStuff` не устанавливает анимации.

1. Установите DLC пака по инструкции выпуска. Если танцы уже установлены, повторная установка не нужна.
2. Закройте GTA V. Сохраните копию своего `menyooStuff/FavouriteAnims.xml`.
3. Если старое избранное не требуется, скопируйте файл из папки `menyooStuff` этого комплекта в одноимённую папку игры.
4. Чтобы сохранить старое избранное, вместо замены файла вставьте строки из `FavouriteAnims-entries.txt` перед закрывающим тегом `</PedAnims>` своего файла.
5. В сюжетном режиме выберите женского MP персонажа. В Menyoo откройте Player Options → Animations → Favorites и выберите `pubg@VD_…`, клип `dance`.

Обычный Menyoo использует общие настройки воспроизведения. Выключайте Loop для Dance 1, Victory Dance 11, Victory Dance 20, BBoom BBoom и MALATANGHLU. Для остальных танцев включайте Loop. Повторы в 20 / BBoom BBoom / MALATANGHLU уже включены в сами файлы.

Все анимации используют всё тело. Не включайте блокировку положения. Индивидуальные режимы автоматически выбираются в отдельном разделе ASI Edition.

Для быстрого отключения модов перед GTA Online и восстановления сюжетной сборки: [GTA V Mod Switcher by SPARKYASHH](https://github.com/SPARKYASHH/GTAV-Mod-Switcher).
